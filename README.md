# Rafa & Sammi

Página do pedido de namoro (24/10). Um arquivo só: `index.html`, sem dependências além das fontes do Google Fonts.

## Como publicar no GitHub Pages

1. Crie um repositório novo no GitHub (por exemplo `rafa-e-sammi`).
2. Envie os arquivos desta pasta: `index.html`, `.nojekyll` e este `README.md`.
   - Pelo site: **Add file → Upload files**, arraste os arquivos e clique em **Commit changes**.
   - Ou pelo terminal:
     ```bash
     git init
     git add .
     git commit -m "Página Rafa & Sammi"
     git branch -M main
     git remote add origin https://github.com/SEU-USUARIO/rafa-e-sammi.git
     git push -u origin main
     ```
3. No repositório, vá em **Settings → Pages**.
4. Em **Source**, escolha **Deploy from a branch**, branch **main**, pasta **/ (root)** e clique em **Save**.
5. Em 1 ou 2 minutos o site fica no ar em `https://SEU-USUARIO.github.io/rafa-e-sammi/`.

## Privacidade

No plano gratuito do GitHub, o GitHub Pages só funciona com repositório **público**: qualquer pessoa com o link pode ver a página e o código. O cadeado é só uma brincadeira, não uma proteção real (a senha está dentro do código). A página tem `noindex` para não aparecer no Google.
